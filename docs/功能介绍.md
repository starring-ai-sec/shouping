# 守屏 · 功能介绍

> 一句话：**关掉打扰你的广告，并且告诉你是谁在打扰。**
> 全部判断都在你的手机上完成，App 不申请网络权限。

---

## 一、它解决什么问题

打开一个 App，先看 3–5 秒开屏广告；点一下屏幕，跳到了电商页；关掉一个弹窗，又弹出来一个。

这些体验背后都有具体的广告 SDK 在推。守屏做两件事：

1. **替你按掉那一下** —— 识别「跳过 / 关闭 / ×」并点击；
2. **记下证据** —— 哪个 App 弹了多少条推送、占了你多少分钟、APK 里装了哪些广告 SDK。

不拦网络、不改系统、不装模块、不 root。

---

## 二、三步开始用

| 步骤 | 做什么 | 必须吗 |
|---|---|---|
| ① | 打开**无障碍服务**（系统设置里勾选「守屏」） | **必须**，不开不会动作 |
| ② | 授权**通知使用权** | 可选，缺了报告里没有推送条数 |
| ③ | 授权**使用情况访问** | 可选，缺了报告里没有前台时长 |

可选第四项：**显示悬浮窗**（用于「辅助跳过按钮」和「自动返回」）。
MIUI 路径：设置 → 应用设置 → 守屏 → 其他权限 → 显示悬浮窗 → 允许。

> 部分系统在安装后会重置 `appops`，需**安装之后**再单独允许一次。

## 三、四个能力

### 1. 自动跳过开屏广告

四条通道，从便宜到贵依次尝试，前一条没结果才走下一步：

| 通道 | 做什么 | 典型场景 |
|---|---|---|
| **文案** | 读界面树里的「跳过 / 关闭 / ×」并点击 | 原生广告、WebView 广告 |
| **OCR** | 截角区小块做**端侧**文字识别（离线模型） | 自绘广告，界面树里没有文字 |
| **像素** | 在角区找高对比度的角标块 | 纯图标关闭键（方形 ×） |
| **图标** | 找局部色块 + 与邻域亮度差大的小块 | 照片背景上的 × / 倒计时圈 |

四条通道之外还有一道**准入闸门**：只有在「宿主应用被确认含广告 SDK 痕迹」时，才允许更复杂的界面进入视觉通道；没有 SDK 证据的界面按更严的标准处理。

**目的只有一个：宁可漏一个，也不要在你的正常界面上乱点。**

每次动作前有三道闸：

- **同窗口只动一次**（避免连点）；
- **同应用与全局都有频率上限**（避免被当成自动化脚本，也避免误伤）；
- **禁点名单永不作目标**：同意 / 接受 / 允许 / 授权 / 我知道了 —— 这些按钮一律不点。

点击后还会校验：点了没生效（目标仍在）→ 记为失败；连续失败会静默一段时间，不再纠缠。

### 2. 辅助跳过按钮（需悬浮窗权限）

自动链路搞不定时，屏幕右下角出现小胶囊「跳过广告」，**3.5 秒后自动消失**。

- 点它 = 由无障碍执行关闭；
- 找不到可信的关闭目标 → 发一次返回键；
- 有频率上限，不会变成常驻按钮；
- **你不点，它什么都不做。**

### 3. 自动返回（需悬浮窗权限，**默认关闭**）

比按钮更激进：不用你点，直接发返回键。

**默认关闭**，因为它是所有能力里唯一会「退出应用」的动作——误退的代价远高于多关一个广告。

只在同时满足以下条件时才动：

- 应用**刚启动**（你还没开始操作）；
- 界面是**极简的开屏形态**（不是内容页）；
- **视觉通道确实跑过**（分类器认为像自绘广告）；
- 这个应用**以前真被关过广告**（记忆里有命中记录）；
- 你几秒内**没摸过屏幕**。

**误退自愈**：发出后校验真实前台——如果把你退到了桌面，判定误退，**本机从此不再对该应用自动返回**。最多误退一次。

### 4. 打扰报告 + 成分透视

**打扰报告**：
- 谁占了你最多时间（前台时长排行）；
- 谁弹了最多推送（按条数统计，不存内容）；
- 今天守屏动了多少次、命中记忆几次、走了几次视觉。

**成分透视**：
- 扫描前台应用的 APK，看它装了哪些广告 SDK；
- 内置常见广告 SDK 指纹库，按签名匹配；
- 结果只在本机显示，不上传。

## 四、安全设计（为什么它不会乱点）

| 机制 | 作用 |
|---|---|
| **禁点名单** | 同意 / 接受 / 允许 / 授权 / 我知道了 —— 永不作为点击目标 |
| **同窗口单次动作** | 同一个界面只动一次，不连点 |
| **频率上限** | 同应用、全局各自有上限，避免变成脚本 |
| **策略闸门** | 只有判定为「可处置」才允许执行动作；不确定 → 只观察 |
| **点击后校验** | 点了没生效 → 记失败；连续失败 → 静默 |
| **白名单** | 勾选的应用一律不动作（从应用列表里选，不用输包名） |
| **采样模式** | 只判定、不点击——想先看效果就开这个 |
| **误退自愈** | 自动返回退错一次 → 永久拉黑该应用 |

## 五、明确不做的事

1. **不拦网络**：没有 VPN 通道，也不申请网络权限——数据物理上出不去；
2. **不做输入监听**：不读取你打的字、不记录剪贴板；
3. **不存截图**：正式构建关闭调试落盘；
4. **不存通知内容**：只记条数；
5. **不 root、不装 Xposed / Magisk 模块**；
6. **不上传任何数据**：没有网络权限，也没有统计 SDK。

---

## 六、已知限制

1. **签名证书是本机自建的** —— 将来换正式证书需**卸载重装**，本地数据会清除；
2. **上不了应用商店** —— 无障碍服务用于非无障碍用途，Google Play 与多数国内商店不接受，只能侧载；
3. **Flutter / 游戏类应用**：代码在 `libapp.so` 里，dex 扫描天然为空 → 成分透视会显示「无广告 SDK」，这是事实不是 bug；
4. **部分广告创意关不掉**：退出控件不是「跳过 / 关闭 / ×」文案时，只能靠像素/图标通道，仍可能失败；
5. **release 包读不到日志**（去掉了 debuggable）—— 排查请用「设置 → 导出诊断信息」；
6. **系统应用不烧视觉**：系统启动页/过渡页天生无文本，会被识别为系统应用并跳过视觉通道（避免误判）。

## 七、常见问题

**Q：为什么必须开无障碍？**
A：它是「读界面 + 点一下」的唯一途径。守屏不做输入监听，不读取你输入的内容。

**Q：会不会偷我的数据？**
A：应用没有网络权限。Android 在系统层面禁止它联网——不是承诺，是做不到。自己验：见 [`隐私核验.md`](./隐私核验.md)。

**Q：误点了怎么办？**
A：禁点名单 + 频率上限 + 同窗口单次动作三重限制；自动返回还有误退自愈。若仍发生误点，请提 Issue 并附诊断信息。

**Q：耗电吗？**
A：只在界面变化时触发判定，且视觉通道有预算限制（超预算直接放弃这一帧）。日常使用无明显耗电，但长时间刷短视频类应用会略高——这是无障碍常驻的固有代价。

**Q：支持的 Android 版本？**
A：Android 8.0 及以上（使用无障碍事件与使用情况访问）。已在 Android 13（MIUI）真机验证。
