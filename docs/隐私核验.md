# 隐私核验指南

> 不要相信口号，自己验。
> 本文所有命令都在**你自己的设备**上执行，不需要 root。

---

## 一、核验「不申请网络权限」

这是最硬的一条：应用**没有** `INTERNET` 权限，Android 在**操作系统层面**拒绝它建立任何网络连接——不是"它承诺不上传"，是"它做不到"。

### 方法 A：命令行（最准确）

**Windows / macOS / Linux**（需已安装 Android SDK Build-Tools）：

```bash
aapt2 dump badging shouping-release.apk | grep uses-permission
```

期望输出（只有这三行，**没有 INTERNET**）：

```
uses-permission: name='android.permission.POST_NOTIFICATIONS'
uses-permission: name='android.permission.RECEIVE_BOOT_COMPLETED'
uses-permission: name='android.permission.PACKAGE_USAGE_STATS'
```

若输出里出现 `android.permission.INTERNET` —— **请立即停止使用并反馈**。

> 没有 aapt2？可用 `apkanalyzer manifest permissions shouping-release.apk`，或 GUI 工具（MT 管理器 / APK 分析器）打开「权限」页。

### 方法 B：手机上看（最简单）

1. 安装后打开 **设置 → 应用 → 守屏 → 权限**；
2. 查找「网络」「流量使用」相关项 —— 应当**不存在**；
3. 或在 **设置 → 应用 → 守屏 → 流量使用** 中确认无任何联网记录。

### 方法 C：抓包（想更彻底）

1. 装一个防火墙类工具（如 NetGuard），开启「全部禁止联网」以外的观察模式；
2. 使用守屏一整轮（跳广告 / 看报告 / 扫成分）；
3. 观察网络日志 —— **不应当出现 `com.cobuild.guard` 的任何出站请求**。

## 二、核验「记忆只存哈希」

守屏记住「这个界面是广告」时，落盘的是**哈希**，不是截图、不是文案原文。

### ⚠️ 前提说明（诚实）

这条核验**需要调试包**才能用 `run-as` 直接读文件；公开分发的 **release 包去掉了 debuggable**，`run-as` 会报 `package not debuggable`——这是安全换来的代价，不是缺陷。

如果你有调试包（自行构建）：

```bash
adb shell run-as com.cobuild.guard cat files/agent-memory.txt
```

期望内容形如（每条一行，**无截图路径、无原文**）：

```
T|com.example.app|a3f9c1d2|7b21e0aa|2026-11-16T09:12:33
```

字段含义：`类型 | 包名 | 场景哈希 | 特征哈希 | 时间`。

### release 包可做的替代核验

打开 **设置 → 导出诊断信息**，导出的文本里「运行统计」一节会显示记忆条数，但**不含任何界面内容**——你可以直接把这个文件全文搜一遍，确认没有出现你访问过的页面文字。

## 三、核验「通知只计数」

通知相关数据只存「日期 + 包名 → 条数」，**不存标题、不存正文**。

```bash
# 需调试包
adb shell run-as com.cobuild.guard cat shared_prefs/notify_counts.xml
```

期望内容形如：

```xml
<map>
  <string name="2026-11-16|com.example.app">7</string>
</map>
```

**没有标题、没有摘要、没有发送人。**

---

## 四、核验「截图不落盘」

正式构建中调试落盘开关为 **false**。你可以：

1. 使用一轮后，用文件管理器查看 `Android/data/com.cobuild.guard/` 与 `files/` 目录；
2. 期望：**不出现任何 `.png` / `.jpg`**。

若发现截图文件，请在 Issue 中附上文件路径与截图（这属于严重问题）。

## 五、核验 APK 完整性

下载后先算哈希，与 Release 页面公布值比对：

```powershell
# Windows
Get-FileHash .\shouping-release.apk -Algorithm SHA256
```

```bash
# macOS / Linux
shasum -a 256 shouping-release.apk
```

当前版本 `v0.1.0`：

```
ffb2f23cc2b24e4703a0dea3984c8271c1d6e255a52a8bb4b5259e6869488453
```

## 六、核验签名证书

```bash
apksigner verify --print-certs shouping-release.apk
```

期望：

```
Signer #1 certificate DN: CN=Guard Release, OU=ShouPing, O=Digital Sovereignty, C=CN
```

> ⚠️ 这是**本机自建的测试证书**，不是公开 CA 签发。它的作用是保证「后续版本能被覆盖安装」，不代表身份认证。
> 将来换正式证书时，你需要**卸载重装**（Android 不允许签名不同的覆盖安装）。

## 七、一句话总结

| 想确认的事 | 一条命令 / 一个动作 |
|---|---|
| 它能不能联网 | `aapt2 dump badging ... \| grep INTERNET` → 无输出 |
| 它记了什么 | 调试包 `run-as ... cat files/agent-memory.txt` → 只有哈希 |
| 它存不存截图 | 翻 `files/` 目录 → 没有图片 |
| 文件是否被篡改 | `Get-FileHash` / `shasum -a 256` 比对 |

**以上任何一条不符合，都请直接开 Issue。**
